# 🤖 Charly MD

Charly-MD is a fast and powerful Multi-Device WhatsApp Bot built with Baileys.
Designed for education, automation, and advanced group management.

---

## 👑 Owner

Simbarashe Tembo .A

Powered by SAT Limited

---

✨ Features

- 📚 Educational commands
- 👥 Group management (kick, promote, warnings, etc.)
- 🤖 AI-powered responses
- 🎵 Media downloader & player
- ⚡ Fast and lightweight
- 🔐 Multi-device support

---

🧠 Tech Stack

- Node.js
- Baileys
- JavaScript

---

📦 Installation

git clone https://github.com/Simbarasheat/Charly-MD-
cd Charly-MD-
npm install
npm start

---

🔑 Setup

1. Scan pairing code or QR
2. Wait for bot to connect
3. Start using commands in WhatsApp
